## Run Locally
1. /stablecoin-ecosystem -> pnpm i
2. /stablecoin-ecosystem -> pnpm dev:infra
3. /stablecoin-ecosystem -> pnpm db:migrate
4. /stablecoin-ecosystem -> pnpm db:generate
5. /stablecoin-ecosystem -> pnpm dev:all
6. /stablecoin-ecosystem/apps/mobile -> npm i
7. /stablecoin-ecosystem/apps/mobile -> npm start
